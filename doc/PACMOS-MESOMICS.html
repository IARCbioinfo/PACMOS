Introduction

PACMOS is an R package designed to project new query samples into a reference multi-omics latent space derived from MOFA models, enabling sample-level interpretation within an established biological context. It is particularly suited for translational and cancer multi-omics applications where robust comparison of new samples against established molecular reference cohorts is required.

This vignette demonstrates the PACMOS workflow using the pleural mesothelioma tumours dataset from the MESOMICS cohort, based on the integrative multi-omics framework described at https://doi.org/10.1038/s41588-023-01321-1.

The reference datasets required by PACMOS are provided within the package under inst/extdata/MESOMICS_references/. These reference objects consist of MOFA-compatible matrices where rows correspond to genes or molecular features and columns correspond to reference samples across multiple omics layers.

Query samples are expected as one or more CSV files in which the first column contains gene or feature identifiers, followed by one or more columns representing query samples. Query datasets should use feature identifiers compatible with the reference matrices and may contain one or several omics modalities corresponding to the reference MOFA views.

This vignette demonstrates how to:

  1. Install PACMOS
  2. Add query samples to MOFA reference inputs
  3. Run MOFA2 retraining
  4. Project query samples into the reference MOFA latent space
  5. Infer archetype weights of query samples
  6. Visualize query samples within Pareto archetype space

Step 0: Installation

Before using PACMOS, create the required Conda Python environment from the package environment file.

Linux/macOS

Open a terminal and run:

git clone https://github.com/IARCbioinfo/PACMOS.git
cd PACMOS

conda env create -f pacmos_env.yml
conda activate pacmos_env

which python

The last command returns the Python executable from the pacmos_env Conda environment, for example:

/home/user/miniconda3/envs/pacmos_env/bin/python

Windows

Download the PACMOS repository as a ZIP file from GitHub and extract it. Then open the Anaconda Prompt and run:

cd <path-to-PACMOS>\PACMOS-main

conda env create -f pacmos_env.yml
conda activate pacmos_env

where python

This returns the Python executable from the pacmos_env Conda environment, for example:

C:/Users/YOUR_USERNAME/miniconda3/envs/pacmos_env/python.exe

Install PACMOS

Install PACMOS from GitHub in R:

# install.packages("devtools")
devtools::install_github(
  "IARCbioinfo/PACMOS",
  dependencies = TRUE
)

Set the Python path before running the vignette

PACMOS uses the PACMOS_PYTHON environment variable to identify the Python executable from the pacmos_env Conda environment.

Before running or rebuilding the vignette locally, set this variable in your R console.

Sys.setenv(
  PACMOS_PYTHON =
    "/home/user/miniconda3/envs/pacmos_env/bin/python"

Step 1: Add query samples to MOFA inputs

This function integrates one or more query samples into reference multi-omic MOFA input matrices using an incremental approach. For each query sample, it aligns gene identifiers with the reference matrices, inserts observed values into the corresponding data layer, and fills all other layers with NA to maintain a consistent structure across views.

The function creates a structured output directory where each query sample has its own folder, containing an inputs/ subdirectory with all .RData matrices required for downstream MOFA training.


## -----------------------------------------------------------------------------
print('Starting Step 1')
#> [1] "Starting Step 1"
PACMOS::s1_add_sample_to_mofa(
  query_matrix_path = query_csv,
  mofa_dir = mofa_dir,
  value_data_types = c('D_exprB_MOFA'),
  outdir = out_dir,
  python_bin = python_path
)

Step 2: Train MOFA models

This function trains MOFA models for each query sample using the prepared input matrices. It loads the multi-omic inputs generated in Step 1, configures the model according to the specified views and data types (including binary layers), and runs MOFA.

Each query sample is processed independently, producing a trained MOFA model.

print('Starting Step 2')
#> [1] "Starting Step 2"

PACMOS::s2_run_mofa(
  models_dir      = out_dir,
  matrices_subdir = "inputs",
  num_factors = 10,
  convergence_mode = "slow",
  maxiter = 10000,
  use_basilisk = FALSE,
  skip_existing = TRUE,
  python_bin      = python_path,
  views_map = c(
    RNA     = "D_exprB_MOFA",
    MethPro = "D_met.proB_MOFA",
    MethBod = "D_met.bodB_MOFA",
    MethEnh = "D_met.enhB_MOFA",
    Total   = "D_cnv_MOFA",
    Minor   = "D_loh_MOFA",
    Alt     = "D_alt_MOFA"
  ),
  binary_views = "Alt"
)

Step 3: Visualize query samples

This function projects query samples into the reference/retrained latent factor space and generates quality control visualizations. It compares the learned latent factors of retrained models with reference axes, computes correlations, and produces diagnostic plots to assess how well the query samples align with known biological structure.

The outputs are saved as PDF files for each sample in the outputs directory inside each query sample folder.

print('Starting Step 3')
#> [1] "Starting Step 3"

sample_dirs <- list.dirs(out_dir, recursive = FALSE, full.names = TRUE)
sample_dirs <- sample_dirs[dir.exists(file.path(sample_dirs, "inputs"))]
sample_ids <- basename(sample_dirs)

s3_results <- list()

for (id in sample_ids) {
  s3_results[[id]] <- PACMOS::s3_plot_query_samples_mofa(
    models_dir      = out_dir,
    matrices_subdir = "inputs",
    query_sample    = id,
    reference_LFs   = reference_LFs,
    reference_axes  = c("Morphology_LF", "Adaptive-response_LF"),
    group           = "group1",
    python_bin      = python_path
  )
}

Interpreting Step 3 quality control

Step 3 checks whether the latent factors learned after adding the query sample can be aligned back to the original reference MOFA space.

The QC PDF contains three main diagnostics (Good alignment is indicated by high absolute correlation, a clear diagonal trend in the scatter plot, and relatively low RMSE):

  1. Factor assignment summary: shows which retrained MOFA factor was matched to each reference latent factor.

  2. Correlation heatmap: The heatmap shows correlations between retrained MOFA factors and reference latent factors. Rows are retrained MOFA factors and columns are reference axes. The black boundary marks the selected factor for each reference axis.

sample_to_show <- sample_ids[1]

s3_results[[sample_to_show]]$plots$alignment_heatmap

  1. Scatter plots: The scatter plot compares reference LF values with aligned retrained LF values. A strong diagonal trend and high correlation indicate successful alignment.
s3_results[[sample_to_show]]$plots$scatter_by_axis$Morphology_LF
#> `geom_smooth()` using formula = 'y ~ x'

The projection plot shows the query sample highlighted in red within the reference latent factor space (grey points).

s3_results[[sample_to_show]]$plots$projection_pairs[[1]]

Step 4: Infer archetype weights

This function estimates the contribution of predefined biological archetypes to each query sample using a fuzzy weighting approach. Based on the latent factor coordinates obtained from MOFA, it calculates the degree to which each sample belongs to each archetype.

The result is saved as a csv file in the outputs directory.

print('Starting Step 4')
#> [1] "Starting Step 4"

archetype_coords <- data.frame(
  Archetype = c("Cell division", "Tumor-immune-interaction", "Acinar"),
  Morphology_LF = c(-3.59733245242571, -1.79807036681759, 3.85856701073313),
  `Adaptive-response_LF` = c(-2.39600999565261, 3.56348237698459, -0.825586204203109),
  stringsAsFactors = FALSE,
  check.names = FALSE)

PACMOS::infer_fuzzy_weights(
  models_dir      = out_dir,
  coord           = archetype_coords,
  n_archetypes    = 3,
  input_type      = "stable",
  reference_axes = c("Morphology_LF", "Adaptive-response_LF")
)
